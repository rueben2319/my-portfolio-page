

# Single-Page Academic Portfolio for Dr. Isaac Rhinnexious Fandika

## Overview
A professional, single-page academic portfolio website for Dr. Isaac Rhinnexious Fandika — an irrigation agronomist and Chief Agricultural Research Scientist at DARS, Malawi. The site will be clean, research-focused, and responsive with a deep teal/green accent color scheme aligned with agriculture/water themes.

## Design Direction
- **Style**: Clean academic layout with Inter font for headings and system serif for body text
- **Color palette**: Near-black ink, slate secondary text, deep teal (#0f766e) accent
- **Layout**: Single scrollable page with sticky navigation, max-width ~1100px, card-based sections
- **Responsive**: Mobile-first, works well on all screen sizes
